# DÉPANN’TECH — GitHub Pages + Administration

## Accès
- Site : `index.html`
- Administration : `admin.html`
- Un bouton **⚙ Administration** est visible en bas du site.

## Administration
Connectez-vous avec votre compte GitHub, le dépôt et un token fine-grained ayant **Contents → Read and write** sur ce dépôt.

Vous pouvez modifier les coordonnées, textes, statistiques, services, produits, logo, photo principale et photos produits. Les fichiers `data.json` et `uploads/` sont enregistrés dans le dépôt.

## Devis
Les demandes de devis sont envoyées à l’adresse configurée dans Réglages via FormSubmit. La page **Demandes de devis** de l’administration indique l’adresse de réception et explique le test. GitHub Pages ne fournit pas de boîte mail native.

Ne partagez jamais votre token GitHub.


## Accès administration
Depuis le site, le bouton **⚙ Administration** est maintenant visible dans le menu (et en bouton flottant). Il ouvre `admin.html`. La section formulaire de devis intégrée dans la page d'accueil a été supprimée : le devis s'ouvre uniquement dans la fenêtre « Devis gratuit » / « Demander un devis ».
